# Changelog

## 0.1.0

- One MIT npm package for JavaScript/TypeScript, DOM, React and Node SSR.
- Prepared synchronous reads, explicit fallback and bundled/offline startup.
- Signed delivery, bounded workers, atomic cache and monotonic revisions.
- Startup-only updates, explicit refresh and optional manual activation.
- Optional bounded SDK diagnostics with separate write-only credentials.
- Matching self-hosted JavaScript/worker assets and a development-only generator.
